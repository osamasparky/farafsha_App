# 🎮 تطبيق «لمّة» (Lammah) | منصة الألعاب الجماعية للجلسات والسهرات

> **تطبيق عربي يحوّل الجلسة إلى مجموعة ألعاب قصيرة وممتعة تعتمد على الكلام والتخمين والتمثيل والمعرفة المشتركة.**

---

## 🏗️ هيكلية المشروع (Monorepo Architecture)

```
d:\projecs\لمة/
├── backend/          # خادم Laravel 11/13 + Filament v3 + REST APIs + SQLite/MySQL
│   ├── app/
│   │   ├── Filament/Resources/   # لوحة تحكم Filament لإدارة الألعاب والمحتوى والبطاقات

│   │   └── Models/               # Game, Pack, ContentItem, Room, RoomPlayer, GameSession
│   ├── database/
│   │   ├── migrations/           # جداول الألعاب والحزم والبطاقات والغرف ولوحة الشرف
│   │   └── seeders/              # البذر الأولي لـ 6 ألعاب MVP مع بطاقاتها كاملة
│   └── routes/api.php            # مسارات API المخصصة للموبايل
│
├── mobile/           # تطبيق Flutter متعدد المنصات (iOS & Android)
│   ├── lib/
│   │   ├── core/
│   │   │   ├── theme/            # نظام التصميم المعتمد (الألوان، الخطوط Cairo، الأنماط)
│   │   │   ├── widgets/          # أزرار ثلاثية الأبعاد تفاعلية، بطاقات، خلفيات
│   │   │   └── router/           # مسارات التطبيق عبر GoRouter
│   │   └── features/
│   │       ├── splash_onboarding/# شاشة البداية والشعار
│   │       ├── mode_selection/   # اختيار نمط اللعب (محلي / أونلاين)
│   │       ├── home/             # الرئيسية مع تبويبات الألعاب والشبكة وشريط التنقل
│   │       ├── game_lobby/       # إعدادات اللعبة والغرف الأونلاين
│   │       ├── games/            # شاشات اللعب التفاعلية (أمثال شعبية، إفيهات، ...)
│   │       ├── leaderboard/      # منصة التتويج ولوحة الشرف
│   │       └── profile/          # الملف الشخصي وإحصائيات اللاعب والأوسمة
│   └── assets/data/seed_games.json # قاعدة بيانات أوفلاين مدمجة للعب بدون إنترنت
│
└── docs/             # وثائق التصميم والمعمارية وجداول البيانات
```

## 🚀 تشغيل الباك إند (Laravel Backend + Filament)

1. الانتقال لمجلد الباك إند:
   ```bash
   cd backend
   ```
2. تثبيت الحزم (تم مسبقاً):
   ```bash
   composer install
   ```
3. تشغيل خادم التطوير والويب سوكت:
   ```bash
   php artisan serve
   # لتشغيل خادم الـ WebSockets اللحظي للغرف:
   php artisan reverb:start
   ```
4. فتح لوحة تحكم المشرف (Filament):
   - الرابط: `http://127.0.0.1:8000/admin`
   - البريد الإلكتروني: `admin@lammah.app`
   - كلمة المرور: `password`

## 📱 تشغيل تطبيق الموبايل (Flutter Mobile App)

1. الانتقال لمجلد الموبايل:
   ```bash
   cd mobile
   ```
2. جلب الحزم:
   ```bash
   flutter pub get
   ```
3. تشغيل التطبيق على المحاكي أو جهاز حقيقي:
   ```bash
   flutter run
   ```

## 🎯 الألعاب المعتمدة في النسخة الأولى (MVP 0)
1. **أمثال شعبية** (كمّل المثل الشعبي)
2. **جمل مشهورة** (إفيهات الأفلام والمسلسلات)
3. **مين أنا؟** (تخمين الشخصيات بأسئلة نعم/لا)
4. **ممنوع تقول** (شرح الكلمة بدون المحظورات)
5. **حقيقتان وكذبة** (اكتشف الكذبة بين الحقائق)
6. **سؤال على السريع** (معلومات عامة وتحدي السرعة)
